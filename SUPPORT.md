# Getting help with Beam

## Usage questions

Use [GitHub Discussions](https://github.com/TAGISWILD/beam-tv/discussions) for
setup help, media compatibility questions, ideas, and general conversation.

## Bugs

Search [existing issues](https://github.com/TAGISWILD/beam-tv/issues) first.
If the problem is new, use the bug-report form and include:

- Samsung TV model and model year;
- Tizen and firmware versions;
- USB or network source;
- media container and codecs, when relevant; and
- precise reproduction steps.

Remove personal paths, local IP addresses, server names, and private media
details before posting.

## Security

Do not open a public issue for a vulnerability. Follow
[SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.
